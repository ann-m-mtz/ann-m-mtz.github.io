Una identidad visual creada para convertir una celebración personal en un sistema gráfico propio.

Contexto

El punto de partida de la identidad

El proyecto comenzó con una exploración de estructuras, elementos florales y patrones que permitieran construir un lenguaje visual propio para la celebración. Estos primeros trazos establecieron una base para desarrollar el símbolo, los recursos gráficos y sus aplicaciones posteriores.
