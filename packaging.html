Contexto

Este proyecto consistió en el desarrollo de una línea de empaques para productos adaptógenos construida a partir de ilustraciones digitales originales. Cada producto recibió una ilustración específica diseñada para comunicar su identidad dentro de la colección, manteniendo al mismo tiempo una relación visual clara con el resto de la línea.

Más que utilizar la ilustración como un recurso decorativo, el objetivo fue convertirla en uno de los elementos principales del sistema gráfico. Las ilustraciones funcionan como puntos de reconocimiento para cada producto y ayudan a construir una identidad visual coherente, diferenciada y memorable dentro de la colección.

Retos del proyecto ↓

01

Ilustración aplicada

Desarrollar ilustraciones capaces de funcionar tanto como piezas independientes como elementos integrados al empaque final.

02

Diferenciación de productos

Crear identidades individuales para cada producto sin perder la sensación de pertenecer a una misma colección.

03

Sistema visual coherente

Mantener consistencia entre ilustraciones, composición y jerarquías visuales.

Pruebas de impresión

Registro compartido por la clienta durante la etapa de pruebas de impresión.

Aunque corresponde a una fase previa al ensamblado final, permite observar la aplicación física del sistema gráfico desarrollado para la colección.
